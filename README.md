# 교복 사진관 — 사진 촬영형 웹 앱 / 부스 모드 1.0

## 먼저 알아둘 내용

이 앱은 실시간 AR이나 생성형 AI 가상 피팅이 아닙니다. 제공된 정면 교복 인물 2명과 운동장 배경을 고정한 사진에, 촬영하거나 선택한 사진의 얼굴 피부 영역을 맞춰 넣는 브라우저 합성 앱입니다.

교복 종류를 선택하는 화면은 없습니다. 한 명/두 명 체험과 사진의 얼굴 자리(왼쪽/오른쪽)만 고릅니다. 한 명은 선택한 자리만 바뀌며 다른 자리는 원래 모델 얼굴입니다. 성별을 추정하지 않습니다. 둘이 체험은 한 장에 두 얼굴이 나오는 사진을 사용합니다.

몸의 자세, 머리카락, 귀, 목, 손은 기준 사진에 남습니다. 밝은 정면 사진이 가장 유리합니다. 결과의 얼굴 유사성·이음새·색상이 완벽하다고 보장하지 않습니다. 실제 행사에서는 반드시 결과를 확인해 주세요.

**배경 확인:** 제공된 배경 이미지 간판에 HANYANG ELEMENTARY SCHOOL이 표시되어 있습니다. 실제 한신초등학교 배경으로 확인된 사진이 아니며, 사용자 제공 이미지를 그대로 사용했습니다. 학교 홍보나 공식 행사에 사용하기 전에 간판과 배경을 확인·교체해 주세요. AI로 만든 교복 이미지의 로고와 디자인 역시 실제 납품품과 다를 수 있습니다.

## 1. 가장 쉬운 적용 — 기존 GitHub Pages 교체

압축을 풀고 이 폴더의 *내용물*을 기존 저장소의 맨 위로 올립니다. ZIP 파일 자체나 ZIP을 감싼 상위 폴더를 올리지 마세요.

필수 파일:

```
index.html
studio.html
runtime.json
assets/
  scene.jpg
  style.css
js/
  app.js
  compositor.js
```

이전 앱의 index.html만 바꾸면 안 됩니다. assets와 js 파일도 함께 교체해야 합니다. 배포 후 PHOTO BOOTH 1.0 표시를 확인하세요. 옛 앱의 assets 파일이 남아 있어도 충돌하지 않지만, 새 scene.jpg와 js/app.js가 정확한 위치에 있어야 합니다.

Pages의 게시 위치는 main / (root)입니다. 이미 Pages를 사용 중이면 동일한 주소를 그대로 사용합니다. 부스 화면은 index.html, 일반 사진 화면은 studio.html 또는 index.html?mode=studio 입니다. 부스 화면/일반 화면 버튼으로도 전환할 수 있습니다.

GitHub 공식 안내: https://docs.github.com/ko/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 2. 부스 운영 순서

1. 행사 전에 노트북/태블릿과 카메라를 연결하고, Chrome 등 브라우저에서 실제 주소로 엽니다.
2. 운영자 설정의 ‘자동 인식 미리 준비’를 눌러 연결을 확인합니다.
3. ‘전체 화면’ 버튼을 누릅니다. 브라우저에 따라 전체 화면을 지원하지 않을 수 있습니다. 노트북은 브라우저의 F11도 사용할 수 있습니다.
4. 참여자 수와 얼굴 자리를 정하고, 촬영에 대한 허락 확인란을 체크합니다.
5. ‘카메라로 시작’ → ‘3초 뒤 촬영’을 누릅니다. 촬영 전에는 원본 카메라만 보입니다.
6. 한 장을 찍은 뒤 카메라가 꺼지고 얼굴을 합성합니다. 영상 녹화 기능은 없습니다.
7. 결과를 확인하고 ‘사진 저장하기’ 또는 ‘사진 인쇄’를 누릅니다.
8. ‘다음 체험자’를 누릅니다. 앱이 보관한 원본·얼굴 좌표·합성 캔버스·내부 다운로드 URL을 정리하고 처음 화면으로 돌아갑니다.

90초 동안 조작이 없으면 자동으로 처음 화면으로 돌아갑니다. 운영자 설정에서 60/90/120초 또는 끄기를 고를 수 있습니다. 일반 화면 모드에서는 자동 초기화하지 않습니다.

촬영 허락은 앱 체크 하나로 법적 요건 전체가 충족된다는 의미가 아닙니다. 학교가 정한 촬영·저장·이용 안내를 별도로 진행하세요.

## 3. 카메라 없이 사진으로 체험

허락 확인 후 ‘찍어 둔 사진 사용하기’를 누릅니다. 20MB 이하 JPG/PNG/WebP를 권장합니다. HEIC를 브라우저가 해독하지 못하면 JPG로 변환하세요. 사진은 전송하지 않고 브라우저에서 읽습니다. 자동 얼굴 인식은 처음 사용할 때 인식 라이브러리와 모델을 인터넷에서 내려받습니다.

자동 인식이 안 될 때는 ‘자동 인식 대신 직접 맞추기’를 누르고 원본 사진에서 화면 왼쪽 눈, 오른쪽 눈, 입 중앙 순서로 세 점을 지정합니다. 두 명 체험에서는 사진의 왼쪽 자리에 넣을 얼굴부터 지정하고, 이어 오른쪽 자리에 넣을 얼굴을 지정합니다. 이 방식은 자동 특징점 인식보다 윤곽 정확도가 낮습니다.

## 4. 기기 안에서 실행 — 호스팅 없이

컴퓨터에 Python 3가 설치되어 있으면:

- Windows: start_windows.bat를 더블클릭합니다.
- 다른 운영체제: 이 폴더에서 `python3 start_local.py`를 실행합니다.

브라우저가 열리고 http://localhost:8765/ 형태의 주소가 표시됩니다. 실행 중인 검은 창(서버 창)은 닫지 않습니다. 서버는 127.0.0.1에만 연결되어 같은 컴퓨터에서만 접속됩니다. 다른 스마트폰에서 이 주소로 접속할 수는 없습니다. HTML 파일을 더블클릭하는 file:// 실행은 권장하지 않습니다.

카메라에는 HTTPS 주소 또는 localhost, 그리고 사용자 권한 허용이 필요합니다. 인앱 브라우저보다 Chrome/Safari에서 주소를 직접 여는 것을 권장합니다.

참고: https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia

## 5. 선택 사항 — 오프라인 모델 준비

기본 ZIP에는 무거운 MediaPipe 모델/실행 파일을 넣지 않았습니다. 기본 상태(runtime.json의 local:false)에서 첫 자동 인식은 인터넷 연결이 필요합니다. 유료 API나 API 키는 사용하지 않습니다.

인터넷이 되는 컴퓨터에서 Python 3로 `python prepare_offline.py`를 한 번 실행하면 고정 버전의 실행 파일과 모델을 vendor, models 폴더에 받습니다. 모든 다운로드가 성공한 뒤에만 runtime.json을 local:true로 바꿉니다. 실패하면 기본 모드를 유지합니다. 파일별 SHA-256 기록도 남깁니다.

그 뒤 컴퓨터의 start_local.py로 열면 네트워크 없이 실행하도록 구성되어 있습니다. 이 환경에서는 실제 모델 파일 다운로드를 완료하지 못했으므로 **현장에서 인터넷을 끈 실제 테스트 후** 오프라인 사용을 결정해 주세요. 파일을 로컬에 받았더라도 file://가 아니라 localhost 서버로 실행해야 합니다.

## 6. 사진 저장과 인쇄

저장은 고정 사진 크기인 1440×1080 JPG입니다. 촬영 얼굴 지정 안내선은 저장되지 않습니다. ‘교복 체험 · 합성 사진’ 표시를 남깁니다. 인쇄는 브라우저의 인쇄 대화상자를 엽니다. 무인 자동 인쇄, 특정 프린터 직접 제어, QR 다운로드 서버는 넣지 않았습니다.

다음 체험자나 자동 초기화는 이 앱이 가진 화면/메모리 참조를 정리하는 기능입니다. 디스크에 이미 저장된 JPG, 다운로드 기록, 인쇄물, 운영체제의 임시 처리 내용을 원격 삭제하거나 완전 소거하는 기능은 아닙니다. 공용 부스 컴퓨터의 다운로드 폴더는 운영자가 정리해야 합니다.

## 7. 개인정보 처리 구조

- 카메라에는 영상만 요청하고 마이크는 요청하지 않습니다.
- 원본 이미지, 합성 결과, 이름, 얼굴 특징을 서버에 업로드하지 않습니다.
- localStorage, IndexedDB, 쿠키에 참여자 사진을 저장하지 않습니다.
- 얼굴을 식별하거나 누구인지 판단하지 않습니다. 합성 위치를 맞추는 눈·코·입의 좌표만 일시 사용합니다.
- 촬영 직후, 취소, 다음 참여자, 일정 시간 미조작, 카메라 사용 중 탭을 숨긴 경우 카메라 트랙을 정지합니다.
- 기본 자동 인식에서 jsDelivr/unpkg와 Google 모델 저장소로 정적 파일 다운로드 요청이 발생하며, 서비스 제공자는 일반 접속 정보(IP 등)를 볼 수 있습니다. 이 요청에 사진 데이터를 담지 않습니다.
- 공개 GitHub 저장소에는 앱의 기준 이미지와 코드만 올리세요. 실제 참가자의 사진은 올리지 마세요.

## 8. 구현과 수정

- js/app.js: 상태 전환, 촬영, 합성 실행, 모델 로딩, 자동 초기화.
- js/compositor.js: 얼굴 정렬, 외곽 메시 변형, 가장자리 부드럽게 처리, 제한적 색상 보정. 생성형 AI가 아닙니다.
- assets/scene.jpg: 위 두 정면 교복 인물과 제공된 운동장 사진으로 만든 고정 배경. 얼굴 좌표는 이 파일을 기준으로 설정했습니다.
- assets/style.css: 화면 디자인.

기준 사진을 다른 구도로 바꾸면 js/app.js의 fallbackPoints 및 REFERENCE_BOXES도 다시 맞춰야 합니다. 이 앱은 사용자가 매번 교복/배경을 고르지 않는 고정 사진용입니다.

얼굴 자동 인식 공식 문서: https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker/web_js
